# 北京大学选课系统 · 通识课类别筛选

一个 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴 / 油猴）用户脚本，在**北京大学选课系统**（`elective.pku.edu.cn`）的课程列表页上方加入「通识课类别」筛选条，帮你按通识课系列快速筛选课程。

> 仅做**本地显示过滤**：保留页面原有的一切信息（课程号、课程名、学分、教师、限数/已选、意愿值、预选/取消/加入选课计划按钮等），只隐藏不匹配的行。**不包含任何账号密码，也不发起任何选课/退课操作。**

---

## 功能

- 按通识课系列 **一 / 二 / 三 / 四** 及 **未区分** 五类快速筛选
- 一键「全部」恢复、「通识课」只看所有通识课
- 每个按钮实时显示当前页匹配数量
- 筛选选择跨分页自动记住
- 适配页面：**预选 / 补选 / 补退选 / 课程查询**（课程列表）

## 筛选类别说明

| 按钮 | 含义 |
|---|---|
| 全部 | 显示所有课程 |
| 通识课 | 显示全部通识课 |
| 一 | 通识课系列 I（人类文明及其传统） |
| 二 | 通识课系列 II（现代社会及其问题） |
| 三 | 通识课系列 III（人文与自然） |
| 四 | 通识课系列 IV（数学与逻辑） |
| 未区分 | 未标注系列号的通识课（如单独的「通选课」） |

> 系列名称仅供参考；脚本按页面「课程类别」列里的 `通识核心课I~IV`、`通选课I~IV` 字面归类，不区分核心课/通选课。

## 安装

### 前置：安装 Tampermonkey

- **Edge**：Edge 加载项商店搜索「Tampermonkey」安装（中文名为「篡改猴」）。
- **Chrome / Firefox**：对应扩展商店搜索「Tampermonkey」安装。

### 方式一：一键安装（推荐）

浏览器已安装 Tampermonkey 后，直接点击下面的链接（仓库发布后即为本文件的 raw 链接），会弹出「安装脚本」页面，点「安装」即可：

```
https://raw.githubusercontent.com/meravChen/pku-elective-general-edu-course-sorter/main/pku_tsk_filter.user.js
```

### 方式二：手动粘贴

1. 点浏览器右上角 Tampermonkey 图标 →「管理面板」→「+」新建脚本。
2. 清空默认内容。
3. 将 `pku_tsk_filter.user.js` 的全部内容粘贴进去。
4. `Ctrl+S` 保存。

---

## 使用

1. 打开 `https://elective.pku.edu.cn`，正常登录。
2. 进入「**预选**」或「**课程查询**」页面。
3. 课程列表上方会自动出现一行筛选按钮：

   ```
   通识课筛选：全部 通识课 | 一 二 三 四 未区分
   ```

4. 点击对应按钮即可按类别筛选。

- 选课结果请以选课系统、校内门户「我的课表」为准。
- 本工具仅供个人选课参考，请遵守学校选课规定，切勿用于抢课等违规行为。
